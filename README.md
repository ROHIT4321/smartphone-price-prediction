# Smartphone Price Prediction

Predicts smartphone price (INR) from spec data (brand, platform, RAM, storage, battery,
rating) using Linear Regression, Random Forest, and XGBoost, then uses the best model to
answer two questions: how much RAM/storage is worth in price, and which brands carry a
price premium.

## Notebooks (run in order)

1. **`01_eda.ipynb`** — load the raw data, check structure/missing values/duplicates,
   visualize distributions and correlations. Read-only; saves nothing.
2. **`02_preprocessing.ipynb`** — clean columns, encode categoricals, engineer features,
   split into train/test, scale for linear regression. Saves everything downstream needs
   into `artifacts/`.
3. **`03_training_and_prediction.ipynb`** — loads `artifacts/`, trains and evaluates the
   three models, compares them, saves the trained models, then runs the price-sensitivity
   and brand-premium analyses using the best model.

## Setup

Place `Mobile Dataset.csv` in this directory, then:

```bash
pip install -r requirements.txt
jupyter notebook
```

Run the notebooks in the order listed above — `02` and `03` depend on the ones before them
via the `artifacts/` folder (created automatically, not checked into git).
